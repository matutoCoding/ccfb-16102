# 熟成窖外皮演化台（Cave Rind Workbench）

面向天然硬质 / 洗浸皮 / 白霉软质奶酪的网页版熟成窖记录与外皮演化系统。
TypeScript + three.js，外皮完全由手写 GLSL 程序化着色器合成（零贴图），数据全部存本机 IndexedDB。

## 运行

```bash
pnpm install
pnpm dev        # 开发，默认 http://localhost:5180
pnpm build      # 类型检查 + 生产构建
pnpm typecheck  # 仅类型检查
```

首次打开会自动播种一套内置测试数据（3 窖区、6 批次、36 个奶酪轮、半年温湿度与翻刷记录），
其中刻意埋入 3 个漏翻漏刷的问题轮（蓝斑、发黏、压痕）。设置页可一键重置回测试数据。

## 六个页面

| 页面 | 能力 |
| --- | --- |
| 窖区档案 | 分区建档、温湿度曲线、通风口位置、杉木架层位编号表、录入采样 |
| 奶酪轮档案 | 按批次建档，三类奶酪分色，尺寸/入窖日期/架位/外观种子，新建自动分配空位 |
| 外皮查看 | 整层俯瞰与单轮细看双模式、时间轴连续演化、巡检照片上传与差异比对 |
| 翻刷记录 | 翻面/刷皮/抹油/洗盐水时间线，登记作业即时驱动生长模型 |
| 熟成预测 | 真实气候 vs 假设窖温湿度双场景并排，同步时间轴向未来推 6 个月 |
| 设置 | 四类菌种与裂纹参数滑块、刷皮恢复、皮色、数据重置 |

## 架构

```
src/
  core/            领域逻辑（不依赖 three/DOM）
    types.ts       全部领域模型与生长状态契约
    rng.ts         确定性 PRNG（mulberry32 + cyrb128），可复现性的根
    growth.ts      按天积分的外皮生长模型：温湿度、四类菌种、作业干预、褐变、干裂
    colony.ts      由种子派生的菌落落点（霉斑扩张锚点）
    db.ts          IndexedDB 泛型仓储
    store.ts       应用中枢：缓存 + 持久化 + 生长调度（带缓存）
    seed.ts        种子化测试数据
    defaults.ts    默认菌种/裂纹参数
  render/
    glsl/          手写着色器：噪声库、顶点、表面合成、光照
    wheel_geometry.ts   车削桶形奶酪轮
    wheel_mesh.ts       共享几何、独立 uniform 的轮阵
    cave_viewer.ts      场景、相机双模式、拾取、渲染循环
  ui/              DOM 视图、路由、设计系统
```

## 外皮程序化与可复现性（核心约束如何满足）

- **无贴图、物体空间**：所有噪声以三维物体坐标 `vObjPos` 为输入，侧面与上下盖共享同一噪声场，
  天然不存在 UV 接缝；车削几何也不依赖 UV 纹理。
- **无周期重复**：整数 hash（pcg3d）驱动的三维梯度噪声 + Worley，每倍频用旋转矩阵打散轴向，
  放大到毛孔级仍是连续噪声，没有平铺纹理的重复单元。
- **四种霉/菌分层**：白地霉绒毛（高频 fbm）、青霉蓝绿斑（Worley + 域扭曲菌落扩张）、
  螨虫粉状麻点（细 Worley 啃痕）、洗浸橙红黏面（低频平滑湿斑 + 低粗糙高光），各自噪声组合不同。
- **连续生长不跳变**：菌落点由种子固定，生长只改变围绕锚点的扩张半径与覆盖量，按天连续积分；
  拖时间轴是平滑变化。刷皮降低覆盖并按恢复天数长回，久不翻面在贴架面生成压痕湿斑。
- **可复现**：每个轮子的全部随机外观都从 `wheel.seed` 经确定性流派生，生长模型是同输入同输出的纯函数，
  不使用任何帧随机或时间随机。同轮同日关闭页面重开，逐像素一致（见下方验证）。

## 已做的自动化验证

`scripts/` 下是基于 Chrome DevTools Protocol 的零依赖探针（需本机 Chrome）：

- 着色器在真实 WebGL2 编译链接通过、控制台零错误；
- 整页重载前后同一轮同一位置像素 sha256 完全一致（可复现性）；
- 六个页面截图巡检。

## 数据与隐私

所有档案、温湿度、作业记录、巡检照片 Blob 仅存于浏览器 IndexedDB，不发起任何网络请求。
